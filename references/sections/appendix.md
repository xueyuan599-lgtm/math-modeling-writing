# 附录章节模块

## 功能

归档正文放不下的内容：核心程序代码、运行日志、详细推导过程、繁杂图表。

## 输入依赖

- Python 代码目录或代码文件
- 运行结果文件（日志、输出表、补充图）
- 正文中需要补充的推导或图表

## 输出骨架

```markdown
# 附录

## 附录A 核心程序代码

（代码块，含必要注释）

## 附录B 运行结果（可选）

……
```

## 写作规则

- 附录放在论文末尾，参考文献之后。
- 只放正文放不下的内容；关键结果必须留在正文，不放进附录。
- 正文须引用附录，用“详见附录A”等表述。
- 代码要可读：保留核心函数与必要注释，删除无关输出与调试内容。
- 无多余小括号；反 AI。

## 自检清单（强制最后一步）

1. 正文有对附录的引用。
2. 关键结果未藏在附录中。
3. 代码含注释、结构清晰。
4. 无多余小括号。
5. 反 AI。
